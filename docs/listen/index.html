REV-246 listening examples

Each example loops. Switch between the dry take, a convolution with a reference impulse response and REV-246 while it plays: the three stay in sync, so you hear the same moment through each. 20 % wet mix, wets level-matched.

Keys: space plays or stops the example you last used; 1, 2, 3 select dry, IR, REV-246.

Each file is the dry length plus the reverb's tail, and all three are the same length, so the loop point sits after the tail has died away. The reverb is the plugin's own engine at its defaults (FLOAT, no output stage). The IR sources are numbered 1 to 3 and unnamed. Settings, levels and the IR-versus-plugin analysis: README.
